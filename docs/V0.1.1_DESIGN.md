# v0.1.1改修設計

目的はv0.1基盤の安定化。Color Metadata、Frame契約、RIFEの複数時刻とGPU再利用、Source倍率を分離する。
実装前にこの境界を選び、詳細をARCHITECTURE.mdへ反映した。

- カット保護を補間バッチ化より先に適用し、モデル選択と出力順を保持する。
- 画像を全区間分貯めず、最大32時刻の計画と逐次IPCでメモリを制限する。
- 色変換の期待値を一度決め、encoder固有VUIと完成後検査で共用する。
- FrameFormatに高精度型を表現できるようにするが、実処理はRGB8・SDRのまま。
- Python 3.11をWindows+RIFEの基準とし、実機なしの項目はCI/診断/チェックリストで引き継ぐ。
- v0.1.0のテスト対象を削除せず、テストdoubleのみ公開Frame契約に追従させる。
- Motion Director、Artifact、Semantic、HDR VFI、AI Autoの本実装は今回行わない。
